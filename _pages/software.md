# Software

We develop open-source statistical software and computational tools. All software is freely available on GitHub.

---

### BLAZE
**Identifying cell barcodes from long-read single-cell RNA-seq**

[GitHub](https://github.com/shimlab/BLAZE) | Published in [Genome Biology (2023)](https://genomebiology.biomedcentral.com/articles/10.1186/s13059-023-02907-y)

Software for identifying cell barcodes from long-read single-cell RNA-seq data without reference to short-read data.

---

### NanoSplicer
**Accurate identification of splice junctions using Oxford Nanopore sequencing**

[GitHub](https://github.com/shimlab/NanoSplicer) | Published in [Bioinformatics (2022)](https://academic.oup.com/bioinformatics/article/38/15/3741/6594111)

Software for accurately identifying splice junctions using Oxford Nanopore sequencing data.

---

### McSplicer
**Estimating splice site usage from short-read RNA-seq data**

[GitHub](https://github.com/canzarlab/McSplicer) | Published in [Bioinformatics (2021)](https://academic.oup.com/bioinformatics/advance-article/doi/10.1093/bioinformatics/btab050/6124273)

A probabilistic model for estimating splice site usages using short-read RNA-seq data.

---

### multiseq
**Bayesian multi-scale models for Poisson processes**

[GitHub](https://github.com/heejungshim/multiseq) | Published in [AOAS (2024)](https://github.com/heejungshim/multiseq_Shim_et_al/blob/main/manuscript/AOAS1828_multiseq.pdf)

An R package for multi-scale Bayesian analysis of high-throughput sequencing data, modeling count data directly.

---

### WaveQTL
**Wavelet-based genetic association analysis of high-throughput sequencing data**

[GitHub](https://github.com/heejungshim/WaveQTL) | Published in [Annals of Applied Statistics (2015)](http://projecteuclid.org/euclid.aoas/1437397106)

Software for wavelet-based QTL analysis of functional phenotypes from high-throughput sequencing assays.

---

### mvBIMBAM
**Multivariate genome-wide association analysis**

[GitHub](https://github.com/heejungshim/mvBIMBAM) | Published in [PLoS ONE (2015)](http://journals.plos.org/plosone/article?id=10.1371/journal.pone.0120758)

Software for joint analysis of multiple related phenotypes in genome-wide association studies.

---

### BayesCAT
**Bayesian Co-estimation of Alignment and Tree**

[GitHub](https://github.com/heejungshim/BayesCAT) | Published in [Biometrics (2017)](http://onlinelibrary.wiley.com/doi/10.1111/biom.12640/abstract)

Jointly estimates sequence alignment and phylogeny while modeling arbitrary-length overlapping indel events.
